# Project handoff

A project migration report includes the source repository and exact SHA,
history-preservation method, destination repository and visibility, baseline
version/SHA/profile, local and CI results, deploy target and active revision,
production verification, rollback point, remaining questions, and confirmation
that secrets and unrelated customer data were not copied.

Do not remove the old project path until the destination history, files,
settings, checks, and deployment have been independently verified.
